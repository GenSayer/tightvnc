
  TightVNC version 1.3.10
  BUILDING vncviewer and WinVNC

======================================================================

  Building with Visual C++ 4.x (x86, MIPS, Alpha, PowerPC)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

From the vnc_winsrc_msvc4 directory, with the VC++ 4.x environment for
the target CPU set up (PATH, INCLUDE, LIB):

    build.cmd i386            release build for x86
    build.cmd MIPS            release build for MIPS
    build.cmd ALPHA           release build for Alpha
    build.cmd PPC             release build for PowerPC
    build.cmd i386 debug      unoptimised build with debug info

With no CPU argument PROCESSOR_ARCHITECTURE picks one.  Each directory
gets its output in Rel_<CPU> (or Dbg_<CPU>), so builds for different
CPUs can live side by side.  The results are:

    vncviewer\Rel_<CPU>\vncviewer.exe
    winvnc\Rel_<CPU>\WinVNC.exe
    winvnc\Rel_<CPU>\VNCHooks.dll       (copied there by build.cmd)

Each directory can also be built on its own with
"nmake /f msvc4.mak CPU=<CPU> [DEBUG=1]" (build vc2ctl, omnithread,
zlib, libjpeg and VNCHooks first).  Shared settings are in msvc4.inc.
The compiler switches, defines and libraries are the same as in the
Developer Studio makefiles described below, which still work as before.

  Common controls on Windows NT 3.1 / 3.5 (vc2ctl)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The msvc4.mak build defines USE_VC2CTL.  On Windows NT before 3.51 the
programs then use the built-in tab, trackbar, up-down, progress, list
view, tree view and toolbar controls from vc2ctl\ (taken from the
VC++ 2.x tree) instead of COMCTL32, so no COMCTL32.DLL from NT 3.51 is
needed there.  The Options and Properties dialogs also get keyboard
navigation into their tab pages on those systems.

On NT 3.51 and later and on Windows 95, vc2ctl is never called and
COMCTL32 is used exactly as before.  COMCTL32 is loaded at run time
(vc2ctl\vc2gate.h), so comctl32.lib is not linked.

The Developer Studio makefiles and projects do not define USE_VC2CTL.
They build the original code, which handles NT 3.5 with its own
workarounds and needs the NT 3.51 COMCTL32.

  Building from the source distribution
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The source distribution is ready to compile (all required libraries
are included).

Currently, two build environments are supported: MS Visual C++ 6.0 and
MS Visual C++ 2008. The Workspace files for both these environments
are included in the distribution. Use WinVNC.dsw and vncviewer.dsw
workspace files for Visual C++ 6.0; WinVNC.sln and vncviewer.sln
solution files for Visual C++ 2008. Also, solution and project files
for Visual C++ 2005 are available (files with "-vc8" in their name),
but they may be out of date.

Building with Borland C++ 5.5 compiler is not supported any more,
sorry.

  Building from the CVS
  ~~~~~~~~~~~~~~~~~~~~~

The sources in the CVS do not include third-party libraries required
for successful compilation. These are zlib and JPEG libraries freely
available in the source form from the following locations:

  ftp://ftp.uu.net/graphics/jpeg/jpegsrc.v6b.tar.gz
  http://prdownloads.sourceforge.net/libpng/zlib-1.1.4.tar.gz

Please download these libraries prior to compilation. Note that these
archives are in tar+gzip format not very popular in Windows
environments. To unpack the files, either install appropriate
extractors available for Windows platforms, or unpack them on
Unix-like machines.

After you have downloaded and unpacked the libraries, place their
source files to the locations listed below, NOT overriding existing
files:

  zlib library:
    vnc_winsrc/vncviewer/zlib/
    vnc_winsrc/winvnc/zlib/

  JPEG library:
    vnc_winsrc/vncviewer/libjpeg/
    vnc_winsrc/winvnc/libjpeg/

Also, TightVNC compilation requires Microsoft Html Help SDK which can
be freely downloaded from this page:

  http://msdn.microsoft.com/library/en-us/htmlhelp/html/hwMicrosoftHTMLHelpDownloads.asp

Only two files from the Html Help SDK are required for compilation,
HtmlHelp.h and HtmlHelp.lib. Copy both files to the following folders:

    vnc_winsrc/vncviewer/
    vnc_winsrc/winvnc/

After zlib, JPEG and HtmlHelp files are in place, the source is ready
to compile with either MS Visual C++ 6.0 or MS Visual C++ 2008.
